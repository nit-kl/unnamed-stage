# 「ここから、まだ」LIVE #001 edit v2（候補）

> **状態:** 未採用の制作候補  
> **用途:** `LIVE #001` のGodot 2D演出・字幕・仮歌制作  
> **注意:** 歌詞、曲、BPM、尺、歌唱表現は未確定。物語の確定設定ではない。

## 楽曲設計

| 項目 | 候補 |
|---|---|
| BPM | 112 |
| 拍子 | 4/4 |
| 歌唱尺 | 約68秒 |
| 全体尺 | 導入・余韻込み約86秒 |

初回ライブなので、豪華な観客演出ではなく、白い空間へ声が届くほど
光と身体の動きが増えていく構成とする。

## v1からの変更意図

- 「過去を取り戻す歌」ではなく「過去がなくても今から声を置く歌」へ焦点を絞った。
- LIVE #001の映像検証に使えるよう、約1分のライブ編集版へ短縮した。
- 記憶、観客、世界の仕組みを断定せず、伏線の余白を残した。
- 振付と字幕を拍単位で対応させられる行長へ整理した。
