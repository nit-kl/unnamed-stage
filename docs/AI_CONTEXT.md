# AI_CONTEXT

AI、MCP、制作ツールへ渡すための共通コンテキストです。詳細な判断が必要な場合は、
リンク先の正本を参照してください。

## Project

**まだ名前のないステージ**

アニメアイドルのライブ映像と連続SFストーリーを組み合わせた、
YouTube向けオリジナル作品。

## North Star

何もない世界で目覚めたアイドル・白凪うたが、歌によって失われた世界と
自分自身の記憶を取り戻していく、YouTube視聴者参加型ライブストーリー。

## Main Character

**白凪うた / Uta Shiranagi**

- 16歳程度、身長約157cm
- 白に近い淡灰色のミディアムヘア。毛先にごく薄い水色
- 左目は淡い青、右目は薄い灰色
- 未完成に見える白主体の衣装
- 好奇心旺盛で少し不器用。感情が顔に出やすい
- 歌い始めると、普段と対照的に堂々としたアイドルになる

詳細: [白凪うた](characters/uta-shiranagi.md)

## Initial World

空、建物、観客が存在しない真っ白な世界。白い地面と一本のマイクだけがある。

## Core Mechanic

表向きには、うたが歌うことで世界に物が生まれる。真相は新規創造ではなく、
歌に結びついた感情と記憶を介して、失われた世界が復元されている。

```text
歌 → 感情 → 記憶 → 記憶内の存在 → 世界への復元
```

## Audience

YouTube視聴者は作中の「観測者」。うたには姿も声も届かないが、コメントは届く。
歌が記憶を呼び戻し、観測が復元された記憶を世界へ固定する。

## Episode 001

真っ白な世界でうたが目覚める。唯一存在するマイクに触れると、一瞬だけ満員の
ライブ会場が映る。仮題「ここから、まだ」を歌った後、青い花が一輪咲く。
花に触れたうたは無意識に「懐かしい」と言う。最後に `WORLD 0.01%` を表示する。
現在のGodot映像試作はLIVE #001 edit v2の歌詞・112 BPM・86秒構成を使うが、
いずれも制作候補であり未採用。

詳細: [LIVE #001](episodes/live-001.md)

## Visual Direction

- アニメ調
- 初期配色は白、淡灰、淡青
- 初期画面は余白と静寂を重視する
- 世界の復元に合わせ、背景、瞳、衣装へ少しずつ色と情報量を増やす
- LIVE #001では豪華なステージや完成済みのアイドル衣装を使わない

## Themes

- 誰かに覚えていてもらうこと
- 記憶と同一性
- 過去の再現ではなく、現在の自分として生きること

テーマメッセージ:

> 覚えていてくれる誰かがいる限り、歌は消えない。

## Canonical Decisions

- 仮タイトルは「まだ名前のないステージ」
- 主人公は「白凪うた」
- 成長の主軸は観客数ではなく、世界と記憶の復元
- 現在のうた自身も、誰かの記憶から復元された存在
- 最終的に「まだ名前のないステージ」は「白凪うたのステージ」になる
- 映像制作はBlenderとLive2Dを使わず、Godotの標準2D機能を本線とする

## Rejected Ideas

次の案は既存名称・作品との衝突や類似性を避けるため廃止済み。

- `PROJECT LUMINA`
- `星宮ルナ`
- 観客3人から開始する設定
- ファン数を増やしてドームを目指すことを物語の主軸にする案
- デビュー曲名 `First Light`

## Constraints

- 既存アニメ、既存アイドル、既存楽曲を直接模倣しない。
- キャラクター、曲、舞台、物語はオリジナルとして設計する。
- キャラクターはレイヤー分け原画、差分、Godotの2Dリグで表現する。
- AI生成物は権利、利用規約、出典、設定の連続性を確認してから採用する。
- 物語の真相は制作側の情報であり、序盤の公開物では説明しすぎない。
