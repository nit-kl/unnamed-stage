# 世界設定

## White World

物語開始時の世界は完全な白で、空、建物、植物、観客、時間の手掛かりがない。
無限に見える白い地面と、一本のマイクだけが存在する。

白は単なる背景ではなく、記憶が消去された状態を表す。

## 復元の仕組み

序盤では「歌うと物が生まれる」と見せる。制作側の真相は次の通り。

```text
歌
└─ 感情を呼び起こす
   └─ 感情に結びついた記憶を呼び戻す
      └─ 記憶内の存在を世界へ復元する
```

世界は新しく作られているのではない。かつて存在した世界から、記憶だけが
失われていた。

## 観測のルール

歌だけでは、呼び戻された記憶は不安定で消える可能性がある。
誰かに観測されることで、復元された記憶が世界へ定着する。

- うたが歌う: 記憶を呼び戻す
- 視聴者が見る: 記憶を固定する
- コメントや投票: 次に辿る記憶の方向へ影響する

うたには視聴者の姿や声は届かない。コメントだけが「向こう側」から届き、
やがて視聴者を「観測者」と呼ぶようになる。

## 初期の復元候補

順序はエピソード制作時に確定する。現段階の候補:

| LIVE | 復元要素 | 物語上の役割 |
|---|---|---|
| 001 | 青い花 | 初めての変化と「懐かしい」という矛盾 |
| 002 | 空 | 白い閉鎖空間の外側を意識させる |
| 003 | 水 | 記憶を映す、揺らぐ表現を導入する |
| 004 | 木 | 時間と生命の存在を示す |
| 005 | 風 | 見えないものが戻る感覚を表す |
| 006 | 夜 | 「時間がある」ことを確定する |
| 007 | 星 | 遠さ、過去、観測のモチーフを補強する |

## 違和感の育て方

序盤は世界創造に見せ、中盤へ向けて次の違和感を増やす。

- 初めて見た場所の名称を、うたが知っている
- 駅の改札など、存在する前の配置が無意識に分かる
- 物に触れた瞬間だけ、過去らしき映像や音が混ざる
- 復元物が、うた個人の記憶だけでは説明できない
- 満員のライブ会場が断片的に映る

## 視覚的な進行表示

世界の復元は背景だけでなく、次にも同期させる。

- うたの右目へ色が戻る
- 衣装へ新しい色やモチーフが加わる
- ライティングと影が豊かになる
- 環境音や残響が増える
- `WORLD RECOVERY` の値が進む
