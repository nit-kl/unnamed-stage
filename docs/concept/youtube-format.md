# YouTubeフォーマット

## 1話の基本構成

```text
短いストーリーパート
→ ライブ開始
→ オリジナル楽曲
→ ライブ終了
→ 世界の変化
→ 短いストーリーパート
→ 進行表示と次回への問い
```

全話を完全に同じ尺へ固定する必要はないが、ライブと物語のどちらも省略しない。

## 視聴理由

各動画で、最低2つ以上を明確に提供する。

- 新曲や新しいライブ演出を見たい
- 世界の次の変化を知りたい
- うたの正体を考察したい
- コメントや投票の結果を確認したい
- 過去回との視覚的変化を比較したい

## 視聴者参加

動画末尾で、次に見たいものを2〜3候補から尋ねる。

例:

- 海
- 桜
- 夜空

選択は「新しい世界の創造」ではなく、次にどの記憶を辿るかへ影響する。
物語の主要な結末を人気投票だけで変更せず、参加結果を既定の長期構成へ統合する。

## 作中でのコメント

うたはコメントを読めるが、視聴者の姿や声は認識できない。
初期は「誰か見てるのかな？」と話し、物語の進行後に「観測者」と呼ぶ。

## 表示要素

- エピソード番号: `LIVE #001`
- 世界進行度: `WORLD 0.01%`
- 次回の問い
- 必要に応じて歌詞字幕

進行度は物語上の値であり、実際の投票数や制作進捗と直接連動させない。

## Shorts

本編から次のような短尺素材を切り出す。

- 歌のフック
- 世界が復元される瞬間
- うたのリアクション
- 0.1秒の伏線を含む考察誘導

Shortsだけで真相を説明しすぎず、本編へ自然に接続する。
