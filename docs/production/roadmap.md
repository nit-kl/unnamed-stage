# 制作ロードマップ

## 現在の実装

- Godot 4.7.1で起動する `LIVE #001` の86秒演出プロトタイプ
- White World、マイク、記憶フラッシュ、歌唱中の光、青い花、終了表示
- 4種類の全身ポーズ候補と、112 BPM同期の振付・カメラ・照明
- 「ここから、まだ」LIVE #001 edit v2候補の歌詞字幕
- 生成・後処理・連続性の制作記録

キャラクターはポーズ差分画像によるパイプライン検証段階。レイヤー分けリグ、
口形、楽曲音源、台詞音声は未実装。歌詞、BPM、尺も未採用の候補。
