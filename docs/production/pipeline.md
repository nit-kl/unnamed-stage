## ファイル管理

ソースと派生物を分ける。

- Git: 文書、スクリプト、設定、小容量の制作ソース
- Git LFS候補: `.blend`、`.fbx`、`.glb`、高解像度画像、必要な音声ソース
- Git外: レンダーキャッシュ、一時シミュレーション、動画書き出し、AIモデル

Git LFSは利用を決定して初期化してから対象を追加する。大容量ファイルを先に
通常Gitへコミットしない。

## 品質ゲート

各マイルストーンで次を確認する。

- 設定: `AI_CONTEXT.md` と矛盾しない
- 連続性: 瞳、衣装、復元要素の左右・順序が正しい
- 技術: ソースから再現可能で、依存関係が記録されている
- 権利: 直接模倣や不明な素材がない
- 物語: 公開段階を超えたネタバレをしていない
- 映像: 白背景でも輪郭、表情、動きが読み取れる
