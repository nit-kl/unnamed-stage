# 制作パイプライン

## 全体フロー

```text
企画・設定
→ Gitで変更管理
→ AI / MCPによる支援
→ 2D原画・差分制作
→ Godotで2Dリグ・シーン制作
→ 音楽・音声制作
→ 動画編集
→ 品質・権利確認
→ YouTube公開素材
```

## ファイル管理

ソースと派生物を分ける。

- Git: 文書、スクリプト、設定、小容量の制作ソース
- Git LFS候補: 高解像度原画、必要な音声ソース、大容量の中間素材
- Git外: レンダーキャッシュ、一時シミュレーション、動画書き出し、AIモデル

Git LFSは利用を決定して初期化してから対象を追加する。大容量ファイルを先に
通常Gitへコミットしない。

## 品質ゲート

各マイルストーンで次を確認する。

- 設定: `AI_CONTEXT.md` と矛盾しない
- 連続性: 瞳、衣装、復元要素の左右・順序が正しい
- 2Dリグ: 関節、髪、衣装の変形が破綻せず、差分切替が自然
- 技術: ソースから再現可能で、依存関係が記録されている
- 権利: 直接模倣や不明な素材がない
- 物語: 公開段階を超えたネタバレをしていない
- 映像: 白背景でも輪郭、表情、動きが読み取れる
